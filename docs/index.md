# tskit_extras

`tskit_extras` contains tested utilities that extend the
[tskit](https://tskit.dev/tskit/) Python API.

Browse the {doc}`API reference <api>` for documentation generated from the
package docstrings, or work through the {doc}`examples <examples>` for executable
JupyterBook examples.

For installation and project information, see the
[GitHub repository](https://github.com/hyanwong/tskit_extras).
